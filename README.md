# Rumber Cante
Lightweight English-language offline PWA jungle monkey runner, made with HTML, CSS and Canvas JavaScript. No external dependencies.

## Controls
Space, Up Arrow, screen tap or JUMP button to jump. Press again in midair for a double jump. P pauses, R restarts. Score and personal best are displayed.

## Publish with GitHub Pages
1. Create a public repository named `rumber-cante`.
2. Upload all the files **inside** this folder to the repository root, keeping the `icons` folder.
3. In Settings > Pages, deploy from branch `main` and folder `/ (root)`.
4. Open `https://YOUR-USERNAME.github.io/rumber-cante/` and test gameplay, installation and offline mode.
5. Paste the deployed HTTPS URL into https://www.pwabuilder.com/ and use the Windows packaging option.
6. Submit the resulting package in Microsoft Partner Center; acceptance is subject to validation and review.

## Privacy
This version has no ads, accounts, analytics, external API calls or data collection. Best score is saved in localStorage on the device. GitHub Pages and Microsoft may process technical access data under their own policies.
